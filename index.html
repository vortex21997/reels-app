소용돌이 릴스 자동 게시기

Vortex Reels Auto Uploader · YouTube 자동 업로드 도구

이 애플리케이션은 운영자가 직접 제작한 정보성 숏폼 영상(생활·경제·건강 카드뉴스)을 YouTube API를 사용해 운영자 본인 소유의 YouTube 채널 ‘소용돌이’에 매일 정해진 시간에 자동으로 업로드하는 개인용 자동화 도구입니다. 외부에 배포되지 않으며, 운영자 1명만 사용합니다.

▶ 개인정보 처리에 관한 내용은 개인정보처리방침에서 확인할 수 있습니다.

무엇을 하나요

  • 운영자가 만든 영상 파일을 YouTube 쇼츠로 업로드합니다.
  • 업로드 대상이 운영자 본인 채널이 맞는지 확인합니다.
  • 같은 영상을 Instagram·Threads에도 함께 올립니다(YouTube와 별개).

사용하는 YouTube API

  • youtube.videos.insert — 영상 업로드
  • youtube.channels.list — 인증된 채널 확인(읽기 전용)

요청 범위: youtube.upload, youtube.readonly

실행 환경

운영자의 개인 PC(Windows)에서 로컬로 실행되는 스크립트입니다. 호스팅된 웹 서비스가 아니며, 제3자 최종 사용자가 접근하는 공개 서비스가 아닙니다.
