개인정보처리방침

소용돌이 릴스 자동 게시기 (Vortex Reels Auto Uploader) · 시행일: 2026-10-19

‘소용돌이 릴스 자동 게시기’(이하 ‘본 도구’)는 운영자 본인이 사용하는 개인용 자동화 도구입니다. 본 도구는 외부에 배포되지 않으며, 운영자 외의 사용자나 제3자의 개인정보를 수집·저장·공유하지 않습니다.

1. 수집·사용하는 정보

  • 운영자가 직접 제작한 영상 파일, 제목, 설명, 해시태그 — 운영자 본인 채널에 업로드하기 위해서만 사용됩니다.
  • 운영자 Google 계정의 OAuth 인증 토큰 — YouTube에 영상을 업로드하고 인증된 채널을 확인하기 위해 사용됩니다.

본 도구는 다른 사용자의 데이터, 시청 기록, 구독 정보, 댓글 등 운영자 본인 계정 외의 어떠한 정보에도 접근하지 않습니다.

2. YouTube API 서비스 이용

본 도구는 YouTube API 서비스를 사용합니다. 이용 시 다음이 적용됩니다.

  • YouTube 서비스 약관: https://www.youtube.com/t/terms
  • Google 개인정보처리방침: https://policies.google.com/privacy

사용 범위(scope): youtube.upload(영상 업로드), youtube.readonly(인증 채널 확인). 본 도구는 Google 사용자 데이터를 광고 목적으로 사용하거나 제3자에게 판매·양도하지 않습니다.

3. 정보의 저장 및 보안

OAuth 인증 토큰은 운영자의 개인 PC 로컬 저장소에만 보관되며, 외부 서버로 전송되지 않습니다. 영상 호스팅을 위해 영상 파일이 임시로 공개 저장소에 올라갈 수 있으나, 게시가 끝나면 삭제됩니다.

4. 정보의 제3자 제공

본 도구는 수집한 정보를 제3자에게 제공하지 않습니다. 단, 운영자가 선택한 게시 대상 플랫폼 (YouTube, Instagram, Threads)에 영상과 설명이 게시되며, 이는 각 플랫폼의 약관에 따릅니다.

5. 접근 권한 철회

운영자는 언제든지 Google 계정 권한 설정에서 본 도구의 액세스 권한을 철회할 수 있습니다.
